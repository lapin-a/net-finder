# net-finder

한국(DART·KRX)과 미국(SEC EDGAR) 공시 데이터를 모아, 그레이엄식 **넷넷(net-net)** 분석에 쓰는 지표를 분기·연간으로 정리합니다.

## 지표

| 지표 | 계산 |
|---|---|
| 유동자산, 총부채 | 재무상태표 |
| 발행주식수 | DART 일괄: KRX 상장주식수(보통주+우선주) / DART 회사별: 주식총수 현황 / EDGAR: 표지(dei), 없으면 분기 가중평균 주식수 |
| **주당순유동자산** | (유동자산 − 총부채) ÷ 발행주식수. EDGAR는 우선주(임시자본 포함)·비지배지분도 뺌 |
| 순이익 연평균성장률(CAGR) | 3년·5년·10년. 처음·마지막이 모두 흑자일 때만 계산 |
| 순이익 상태 | 흑자 / 흑자전환 / 적자전환 / 적자지속 (N년 전 → 현재) |
| 순이익 연평균 증감 | (현재 − N년 전) ÷ N. 적자 구간에서도 계산되고 방향이 맞음 |
| 자사주매입 | 금액, 매입 주식수, 주식수 전년 대비 증가율 |

## 데이터 출처

| 출처 | 내용 | 인증 | 한도 |
|---|---|---|---|
| [OpenDART](https://opendart.fss.or.kr) | 한국 상장사 재무제표, 주식수, 자기주식 | API 키 | 하루 20,000건 |
| [KRX Open API](https://openapi.krx.co.kr) | 코스피·코스닥·코넥스 일별 종가, 시가총액, 상장주식수 | API 키 (서비스별 이용 신청) | 서비스별 |
| [SEC EDGAR](https://www.sec.gov/os/accessing-edgar-data) | 미국 상장사 XBRL 재무 데이터(companyfacts), 10-K XBRL 원문 | User-Agent(이름·이메일) | 초당 10회 |
| [Alpaca](https://alpaca.markets) | 미국 주가 월봉 (2016년부터, 원래 종가·분할 반영 종가) | 무료 계정 API 키 | 분당 200회 |

## 설치

```bash
pip install -r requirements.txt
cp .env.example .env
```

`.env`에 값을 넣습니다.

```
DART_API_KEY=...
EDGAR_USER_AGENT=이름 이메일
KRX_API_KEY=...
ALPACA_KEY_ID=...
ALPACA_SECRET_KEY=...
```

KRX는 **유가증권·코스닥·코넥스 일별매매정보** 서비스를 이용 신청해야 합니다.

## 사용법

### 목록

```bash
python main.py dart-corps        # DART 회사 고유번호·회사명 → data/dart/corp_codes.csv
python main.py edgar-tickers     # SEC 티커·회사명·CIK → data/edgar/tickers.csv
```

### 한 회사 분석

```bash
python main.py analyze-dart 삼성전자 2015 2025   # 회사명 또는 고유번호, 시작·끝 연도
python main.py analyze-edgar AAPL                # 티커
python main.py analyze-edgar microsoft           # 회사명 또는 그 일부, 대소문자 무관
```

→ `data/analysis/{dart,edgar}/<회사>_분기.csv`, `<회사>_연간.csv`

### 일괄 분석

```bash
# 한국 상장사 전체: 유동자산·총부채·순이익(다중회사 API, 100개씩) + KRX 발행주식수
python main.py analyze-dart-batch 2015 2026

# + 연간 자사주매입 (회사별 호출, 연도당 약 5,500건). 적힌 연도 순서대로 수집
python main.py analyze-dart-batch 2015 2026 --buyback 2025 2024

# 미국: 티커가 A로 시작하는 회사 전체
python main.py analyze-edgar-batch A

# EDGAR 연간 자사주매입 주식수 빈칸을 10-K XBRL 원문으로 채움 (글자 생략 시 전체)
python main.py fill-edgar-buyback A B

# 이미 XBRL·추정으로 채운 칸도 지금 규칙으로 다시 확인 (규칙을 고친 뒤)
python main.py fill-edgar-buyback --recheck

# EDGAR 분기 자사주매입 주식수 빈칸(·금액이 있는데 0주)을 10-Q·10-K XBRL 원문으로 채움
python main.py fill-edgar-buyback-quarterly A B

# companyfacts 자사주매입 주식수 중 이상한 값(음수, 0주, 평균 매입가 이상)을 XBRL 원문 값으로 교체
python main.py fix-edgar-buyback

# 그래도 남은 자사주매입 주식수 빈칸(연간·분기)을 매입 금액 ÷ 기간 평균 주가(Alpaca VWAP)로 추정. us-prices 먼저
python main.py estimate-edgar-buyback

# 일부 회사만 다시 계산 (분석 코드 수정 후). 이후 fill-edgar-buyback 다시 실행
python main.py refresh-edgar PRTH WTBA

# 글자별 결과에 보고기간 종료일 열 추가 (종료일 열이 생기기 전에 만든 결과용, 값은 그대로)
python main.py fill-edgar-ends

# 글자별 결과의 우선주(·출처)·비지배지분·발행주식수·주당순유동자산만 지금 규칙으로 다시 계산 (나머지 열은 그대로)
python main.py fill-edgar-balance

# 글자별 결과를 하나로 합침 (batch_AA 제외, 같은 회사(CIK)는 대표 티커 하나만, CIK 열 추가)
python main.py merge-edgar

# 미국 월별 주가 (Alpaca 무료 계정, 2016년 1월 ~ 지난달). .env에 ALPACA_KEY_ID, ALPACA_SECRET_KEY 필요
# 원래 종가(분할 미반영)·분할 반영 종가·분할배율·VWAP → data/analysis/edgar/주가_월별.csv
python main.py us-prices
```

→ `data/analysis/dart/batch_상장사_{분기,연간}.csv`, `data/analysis/edgar/batch_<글자>_{분기,연간,실패}.csv`,
합친 결과 `data/analysis/edgar/{연간,분기}.csv`

API 응답은 `data/cache/`에 저장됩니다. 한도 초과나 네트워크 오류로 멈춰도 같은 명령을 다시 실행하면 받은 부분은 건너뛰고 이어서 받습니다. DART 일일 한도(오류 020)에 걸리면 거기까지 저장하고 멈춥니다.
제출기한(분기·반기 45일, 사업보고서 90일)에서 30일이 지나지 않은 보고서는 아직 덜 들어왔으므로 캐시하지 않고 매번 다시 받습니다.
상장사 목록은 `data/dart/listed_corps.json`에 저장해 두고, 고유번호 API가 점검 등으로 막히면 이 파일을 씁니다.

### 넷넷 스크리너 (한국)

`analyze-dart-batch` 연간(또는 분기) 결과에 KRX 종가·시가총액을 붙여 조건을 통과한 종목만 저장합니다. DART 호출은 없습니다.

```bash
python main.py screen-dart                   # 최신 연도, 기본 조건
python main.py screen-dart 2024 --ratio 1 --profit 흑자 --profit-years 5 --no-buyback
python main.py screen-dart 2025 --price-date 20261007   # 연말 대신 해당일(직전 거래일) 주가
python main.py screen-dart 2026Q2            # 분기 결과로 (주가는 분기 말일 기준)
python main.py screen-dart --quarterly       # 최신 분기
```

기본 조건 (모두 만족):
- 시가총액 ÷ (유동자산 − 총부채) ≤ 2/3 (`--ratio`). 시가총액은 보통주와 우선주를 합친 값이고, 순유동자산이 0 이하면 제외합니다.
- 최근 3년 순이익 상태가 흑자 또는 흑자전환 (`--profit`, `--profit-years`, `--no-profit`으로 끔)
- 자사주매입 주식수가 전년보다 많음 (`--no-buyback`으로 끔). 매입 데이터는 `--buyback`으로 받은 연도에만 있습니다 (현재 2015~2025년, 전년이 필요해 2016년부터 적용).
  분기 기준일 때는 분기 자사주매입을 수집하지 않으므로 그 분기보다 앞서 끝난 최신 연간 값(현재 2025년 vs 2024년)으로 판단합니다.
- 분기 기준의 순이익 상태는 최근 4분기 합으로 계산합니다.
- 연도·분기를 생략하면 자료가 충분한(가장 많은 기간의 절반 이상) 최신 기간을 씁니다. 결산월이 12월이 아닌 회사 몇십 곳만 있는 기간은 건너뜁니다.

→ `data/analysis/dart/screen_<연도|분기>_<주가기준일>.csv` (시총÷순유동자산이 낮은 순). 조건만 바꿔 다시 실행하면 같은 파일을 덮어씁니다.

### 넷넷 스크리너 (미국)

EDGAR 합친 결과(`연간.csv`, `분기.csv`)에 Alpaca 월말 원래 종가(`주가_월별.csv`)를 붙입니다. 회사마다 회계연도가 달라서 회사별로 기준일에 이미 공시됐을 최신 분기를 고릅니다.

```bash
python main.py screen-edgar                  # 최신 월말 주가, 기본 조건
python main.py screen-edgar 2024-12 --no-buyback
python main.py screen-edgar --lag 60 --ratio 1
```

- 주가: 기준 월 말 원래 종가. 시가총액 = 종가 × 그 분기 발행주식수(표지 값, 주식 종류 합산)
- 재무: 종료일이 기준일보다 45일(`--lag`, 10-Q 제출기한) 넘게 앞서고 9개월 안인 최신 분기. 순이익 상태는 최근 4분기 합 기준
- 자사주매입: 종료일이 기준일보다 90일(`--annual-lag`, 10-K 제출기한) 넘게 앞선 최신 회계연도와 그 전년의 연간 매입 주식수 비교.
  매입 금액이 0으로 공시된 해는 0주로 봅니다 (전년에 안 사고 올해 샀으면 증가)
- 순유동자산 = 유동자산 − 총부채 − 우선주 − 비지배지분. 미국 우선주는 보통주 시가총액에 안 들어가고 총부채에도 없어서 뺍니다
  (상환우선주 같은 임시자본 포함). 예: EHTH는 상환우선주 $4.06억을 빼면 순유동자산이 음수
- 주식 종류가 여럿인 회사(같은 CIK에 보통주 티커가 둘 이상, 순유동자산 > 0)는 그 분기 10-Q·10-K 표지 XBRL의 종류별 주식수 × 종류별 종가로
  시가총액을 다시 계산합니다 (`시가총액_계산` 열, 예: `BF-A 168,480,849주×$26.83 + BF-B 290,383,416주×$26.20`).
  대표 티커 말고 다른 종류의 종가는 Alpaca에서 그 달 월봉을 받습니다. 티커가 없는 종류(비상장 B주 등)는 대표 티커 가격으로 봅니다.
  표지 값은 `data/cache/edgar_xbrl/cover_<CIK>_<종료일>.json`에 저장됩니다.
- 결과에 `재무경과일`(기준일 − 분기 종료일), `우선주_출처`, `발행주식수_출처`(표지 / 가중평균 / 이어 쓴 값 / 표지 종류별 합),
  `같은 회사 다른 티커`(우선주·워런트 제외)를 같이 적습니다. 재무경과일이 180일을 넘으면 두 분기 넘게 지난 재무입니다.
- 비율·순이익 조건과 옵션(`--ratio`, `--profit`, `--profit-years`, `--no-profit`, `--no-buyback`)은 한국과 같습니다.
- 워런트·유닛·권리 티커(나스닥 5글자 W·U·R, `-WT`·`-U` 등)는 뺍니다.

→ `data/analysis/edgar/screen_<기준월>.csv` (시총÷순유동자산이 낮은 순)

## 결과 해석 시 주의

**분기·기간**
- 분기 순이익·자사주매입은 그 분기 3개월치입니다. 4분기는 연간값에서 3분기 누적값을 빼서 구합니다.
- `최근4분기` 열은 직전 4개 분기 합계이고, 분기표의 CAGR·상태·증감은 이 값을 N년 전 같은 분기와 비교합니다.
- EDGAR는 회사의 회계연도 기준입니다. 예: 애플 2025Q1 = 2024년 10~12월. 실제 보고기간 종료일은 `종료일` 열에 있습니다.
- 분기 순이익은 각 분기 보고서에 처음 공시된 값이고, 연간 순이익은 사업보고서(EDGAR는 가장 최근 정정본) 값입니다. 중간에 정정·재작성이 있으면 네 분기 합이 연간과 다릅니다 (1% 넘게 차이: DART 약 4%, EDGAR 약 6%). 연간 판단에는 연간표를 쓰세요.

**발행주식수**
- DART 일괄은 분기말(휴장이면 직전 거래일) KRX 상장주식수입니다. 우선주는 종목코드 앞 5자리가 같고 이름이 보통주로 시작하면 합산합니다. 이름이 줄여 쓰인 우선주(남선알미우 등)도 앞 5자리가 같은 보통주가 하나뿐이면 합산합니다.
- DART 회사별 분석은 반기·사업보고서에만 주식수가 있는 경우가 많아, 빈 분기에는 직전 값이 들어갑니다.
- EDGAR는 공시 표지(dei)의 주식수를 씁니다. 주식 종류별로만 적는 회사(ACN, ACMR, BIO 등)는 companyfacts에 표지 값이 몇 년 전에 끊겨 있어서,
  표지 값이 없는 분기는 그 분기 3개월 **가중평균 주식수**(`WeightedAverageNumberOfSharesOutstandingBasic`)를 씁니다.
  둘 다 있는 분기로 비교하면 75%가 ±2%, 83%가 ±10% 안입니다. 둘 다 없으면 직전 값을 최대 3분기까지만 이어 쓰고 그 뒤는 빈칸입니다.
  출처는 분기표 `발행주식수_출처` 열 (`표지`, `가중평균`, `표지, 2분기 전` 등). 기존 결과는 `fill-edgar-balance`로 이 열만 다시 계산합니다.
- 주식분할 전 연도는 분할 전 주식수 그대로입니다. 예: 삼성전자 2018년 50:1, 애플 2020년 4:1.

**순이익·재무제표**
- EDGAR 우선주 = 임시자본(`TemporaryEquityCarrying…`) + 자본 안의 우선주. 자본 안의 우선주는 청산가치 합계(`PreferredStockLiquidationPreferenceValue`),
  없으면 주당 청산가치(`PreferredStockLiquidationPreference`) × 우선주 주식수(`PreferredStockSharesOutstanding`, 없으면 `…Issued`)와
  장부가(`PreferredStockValue`) 중 큰 값입니다. 예: FBIO 장부가 $3,000 → 주당 $25 × 343만 주 = $8,568만.
  임시자본이 있는 회사는 주식수에 임시자본 우선주가 섞일 수 있어 추정하지 않습니다. 어느 값을 썼는지는 `우선주_출처` 열
  (`임시자본`, `청산가치`, `주당청산가치×주식수`, `장부가`). `장부가`만 있으면 액면일 수 있어 실제 청산가치보다 작을 수 있습니다 (WORX $40, SBFM $13,000).
  비지배지분은 `MinorityInterest`(음수면 0).
- 연결재무제표 우선, 없으면 별도재무제표입니다. 순이익은 비지배지분 포함 당기순이익입니다.
- 은행·보험사는 유동자산을 구분하지 않아 주당순유동자산이 빈칸입니다.
- 금융 자회사가 있는 회사(현대차 등)는 연결 기준 부채가 커서 주당순유동자산이 크게 음수로 나옵니다.

**자사주매입**
- 주식수 증가율은 연간표에서 전년 대비, 분기표에서 연초누적을 전년 같은 분기와 비교합니다. 전년 값이 0이면 빈칸입니다.
- DART 금액은 별도재무제표 현금흐름표의 자기주식 취득입니다. 연결 기준에는 종속회사의 자사주 매입이 섞이기 때문입니다.
- DART 주식수는 '자기주식 취득 및 처분 현황'의 직접취득 + 신탁계약 취득입니다. 기타취득(단주, 주식매수청구권 등)은 뺍니다. 신탁으로 산 경우 현금흐름표 금액은 0인데 주식수만 있을 수 있습니다.
- DART: 자기주식 수량이 미공시이면 매입 금액이 0일 때만 0주로 보고, 금액이 있으면 빈칸입니다. 일괄 분석은 2015~2025 연간을 수집했습니다 (`--buyback 2025 2024 … 2015`).
- EDGAR: 회사가 연도마다 항목명을 바꾸는 경우가 많아 표준 항목 3가지를 모두 합칩니다.
- EDGAR 연간 주식수 빈칸은 `fill-edgar-buyback`으로 10-K XBRL 원문에서 채웁니다. companyfacts에는 차원이 없는 표준 항목만 있어서, 자본변동표의 열(보통주·자기주식 등)에 붙은 값이나 회사 자체 항목이 빠지기 때문입니다.
  - 고르는 순서: 차원 없는 값 → 자본변동표 열(열끼리 최댓값, 주식 종류별이면 합산) → 매입 프로그램별 합계(주식 종류·자본변동표 열이 같이 붙은 값 포함). 같은 단계에서는 표준 항목이 회사 자체 항목보다 우선합니다. 관계사 매입, 세금 원천징수, 결산일 이후 매입, ASR 계약별 같은 차원은 전체 매입의 일부라 쓰지 않습니다.
  - 매입 주식수 항목이 끝내 없으면 **자기주식 잔액 증가분(기말 − 기초)으로 추정**합니다. 실제 값과 비교하면 중앙값은 맞지만 15%는 절반 이하로 나옵니다(같은 해 재발행). 평균 매입가가 같은 회사 ±2년과 3배 넘게 다른 추정치는 버립니다.
  - 10-K 한 건에 3개년이 들어 있어 최신 10-K부터 거꾸로 찾습니다. 받은 결과는 `data/cache/edgar_xbrl/`에 저장해 두고 다시 씁니다.
  - 평균 매입가(금액 ÷ 주식수)가 $0.10~$10,000 밖이면 회사의 입력 오류로 보고 채우지 않습니다.
  - 현재 연간 빈칸 11,055칸 중 약 78%를 채웠습니다 (자세한 결과: [docs/edgar-buyback-fill.md](docs/edgar-buyback-fill.md)).
- `fix-edgar-buyback`은 companyfacts 값 중 음수, 금액이 있는데 0주, 평균 매입가가 범위 밖이거나 ±2년과 3배 넘게 다른 값을 XBRL 원문 값으로 바꿉니다. 맞는 값을 못 찾으면 음수·0주·범위 밖은 빈칸으로 두고, 인접 연도와만 다른 값은 그대로 둡니다.
- 값의 출처는 `자사주매입주식수_출처` 열에 있습니다:

  | 출처 | 뜻 |
  |---|---|
  | `companyfacts` | companyfacts 값 그대로 (`(부호 수정)`이면 음수를 양수로) |
  | `XBRL <항목명> (<단계>)` | 10-K XBRL 원문 값. 뒤에 `companyfacts <값> 대체`가 붙으면 틀린 companyfacts 값을 바꾼 것 |
  | `추정: XBRL <항목명> 기말-기초` | 자기주식 잔액 증가분으로 추정한 값. 전년 대비 증가 조건 등에 쓸 때 주의 |
  | `제외: companyfacts <값> (<이유>)` | 틀린 값이라 비운 칸 (XBRL로 다시 채우지 않음) |
  | `주가 추정: VWAP $<값>, <n>개월 / 이전: <원래 출처>` | 매입 금액 ÷ 기간 평균 주가. 실제 값과 비교하면 연간 62%, 분기 73%가 ±10% 안 |
- `estimate-edgar-buyback`은 XBRL로도 못 채운 칸(연간·분기)을 매입 금액 ÷ Alpaca 월봉 VWAP의 거래량 가중 평균(연간 12개월, 분기 3개월)으로 추정합니다.
  추정 주식수가 발행주식수의 50%를 넘거나, 평균 주가가 같은 회사 인접 기간의 실제 평균 매입가와 3배 넘게 다르면 채우지 않습니다.
  주가가 2016년부터라 그 전 기간은 못 채웁니다. 현재 연간 채움률은 93.6%입니다 ([docs/edgar-buyback-fill.md](docs/edgar-buyback-fill.md) '4차').

**EDGAR 일괄**
- 10-K/10-Q 제출 회사만 대상입니다. 해외 기업(20-F, 40-F)과 재무 데이터가 없는 ETF·펀드 등은 빠지거나 `실패` 파일에 기록됩니다.
- 분석에는 합친 파일 `data/analysis/edgar/{연간,분기}.csv`를 쓰세요. 같은 회사가 여러 티커로 들어간 경우 SEC 대표 티커 하나만 남기고 CIK 열을 붙였습니다. 글자별 파일은 작업용으로, 빈칸 채우기·교체는 글자별 파일에 한 뒤 `merge-edgar`로 다시 합칩니다.
- 회사가 공시에 회계연도를 잘못 적은 경우(엑셀 날짜 일련번호 `43830`, `2107` 등)는 보고기간 종료일과 1년 넘게 어긋나면 같은 회사의 평소 차이로 다시 계산합니다.
- 회사가 공시 표지에 회계연도·분기를 잘못 적어 종료일이 다른 공시가 같은 (회계연도, 분기)로 겹치면(예: ACN 2018-11-30·2019-11-30 분기가 둘 다 2019 Q1), 겹친 공시만 10-K 종료일(회계연도 끝) 기준으로 분기를 다시 계산하고 회계연도는 가까운 10-K의 회사 표기를 따릅니다. 겹치지 않은 공시는 회사 표기 그대로입니다. 결산월을 바꾼 전환기나 회사가 회계연도 표기 방식을 중간에 바꾼 경우 등 약 450건은 겹친 채로 남아 있고, 이때는 종료일이 늦은 공시 값이 들어갑니다.
- 10-K XBRL 원문으로 연간 빈칸을 채울 때도 분기·연간표와 같은 회계연도를 씁니다. 원문의 회계연도(`DocumentFiscalYearFocus`)는 그 10-K가 companyfacts에 없을 때만 쓰고, 틀린 경우(약 0.1%)는 종료일 3개월 전이 속한 연도로 매깁니다.
- 분기 주식수 채우기(`fill-edgar-buyback-quarterly`)는 companyfacts의 공시별 회계연도·분기로 10-Q를 골라, 3개월 값 → 누적값 − 직전 분기 누적값 → 다음 해 같은 분기 공시의 전년 비교값 순으로 찾습니다. 4분기는 10-K 연간값 − 3분기 누적값입니다. 채운 뒤 연초누적과 전년 동기 대비를 다시 계산합니다.
  현재 분기 파일에서 매입 금액 > 0인 57,470칸 중 25.4%가 이 방법으로 채운 값이고(출처 열 `자사주매입주식수(분기)_출처`), 23.0%는 주가 추정입니다.

**미국 주가 (Alpaca)**
- 거래소 상장 종목만 있습니다. EDGAR 티커 5,365개 중 4,602개에 가격이 있고, 빠진 종목은 대부분 장외(OTC) 종목입니다. 2009~2015년은 없습니다.
- `종가`는 분할 미반영 원래 값이라 같은 시점의 공시 주식수와 곱하면 시가총액이 됩니다. `분할배율`(원래 ÷ 분할 반영)은 그 뒤에 분할이 있으면 1이 아니고, 분할 시점에 값이 바뀝니다.
- 월봉의 종가는 그 달 마지막 거래일 종가입니다. 결산일이 월말이 아닌 회사(52·53주 회계연도 등)는 분기말과 며칠 어긋날 수 있습니다.
- 티커는 조회일 기준이라 이름을 바꾼 회사(FB → META)도 예전 가격이 이어집니다. SEC 티커 `BRK-B`는 Alpaca 표기 `BRK.B`로 바꿔 요청합니다.
- 주식 종류가 여럿이고 가격이 크게 다른 회사(버크셔 A·B주 등)는 한 종류의 가격 × 전체 주식수라 시가총액이 틀립니다.
