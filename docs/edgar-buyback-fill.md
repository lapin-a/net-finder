## 2차 보충 (2026-10-08 저녁)

1차 결과에서 남은 3,177칸을 다시 처리했다. 같은 `fill-edgar-buyback` 명령에 다음을 더함:

- **허용 차원 넓히기**: 매입 프로그램 × 주식 종류/자본 구성요소 (NC 등), `StockRepurchaseProgramAxis`(프로그램 축의 다른 이름),
  `LegalEntityAxis`/`ConsolidatedEntitiesAxis` = `ParentCompanyMember`(모회사 = 연결과 주식수 같음).
  그 밖의 차원(관계사 매입, 원천징수, 결산일 이후 매입, ASR 계약별, 사업부문별 등)은 전체 매입의 일부라 쓰지 않음.
  캐시에는 모아 둠 (`tier` 3)
- **자기주식 잔액 증감으로 추정**: 매입 항목을 끝내 못 찾은 연도에만, `TreasuryStockShares`(없으면 `TreasuryStockCommonShares`)
  기말 − 기초가 양수일 때. 출처 열에 `추정: XBRL <항목> 기말-기초`로 표시
- **추정치 거르기**: 평균 매입가가 같은 회사 ±2년(추정 아닌 값) 중앙값의 1/3~3배 밖이면 다시 빈칸 (41칸)
- 캐시 형식을 바꿔(`"v": 3`) 빈칸 있는 회사의 10-K 약 6,000건을 다시 받음 (약 20분)

| 구분 | 1차 후 | 2차 후 |
|---|---|---|
| XBRL 매입 항목으로 채움 | 7,878 | 7,967 (+89) |
| 자기주식 잔액으로 추정 | 0 | 619 |
| 남은 빈칸 | 3,177 | 2,469 |
| 채움률 | 71% | 78% |

## 3차: companyfacts 값 교체 (2026-10-09)

`python main.py fix-edgar-buyback`. companyfacts에서 온 주식수 중 이상한 값을 찾아 10-K XBRL 원문 값으로 바꿨다.

- 의심 기준: 음수 / 매입 금액이 있는데 0주 / 평균 매입가가 $0.10~$10,000 밖 / 같은 회사 ±2년 중앙값과 3배 넘게 차이
- XBRL 값은 범위 안이고, 비교 대상이 있으면 ±2년 중앙값의 1/3~3배 안이면서 원래 값보다 가까울 때만 사용
- 못 바꾼 경우: 음수는 부호를 바꾼 값이 맞으면 그 값, 아니면 음수·0주·범위 밖은 빈칸
  (출처 `제외: companyfacts <원래 값> (<이유>)`, fill-edgar-buyback이 다시 채우지 않음). 인접 연도와만 다른 값은 그대로

| 이유 | XBRL로 교체 | 부호 수정 | 비움 | 그대로 |
|---|---|---|---|---|
| 0주 | 88 | | 202 | |
| 범위 밖 | 23 | | 99 | |
| 음수 | 65 | 9 | 4 | |
| 인접 연도와 불일치 | 114 | | | 377 |
| **합계 981** | **290** | **9** | **305** | **377** |

예: AAPL 2013 1,940만 주 → 3억 2,884만 주(분할 반영, $69.5), ADSK 2009 −270만 → 270만, ARW 2015 84억 주 → 1,225만 주,
BMY 2022 4,000만 → 1억 900만 주($73). HOFT 2024, ZTS 2025는 맞는 값을 못 찾아 빈칸.

한계:
- 비교 대상이 없으면 범위만 확인 → SCI 2014(12만 2천 주, 평균 $1,991)처럼 XBRL 값도 틀린 경우가 남음
- 그대로 둔 377칸 중 상당수는 주식분할 전후 값이 섞인 경우(예: NOG 2020년 1:10 병합)로 보임 → 주식분할 보정과 함께 처리

## 4차: 주가로 추정 (2026-10-09)

`python main.py estimate-edgar-buyback` → `merge-edgar`. XBRL로도 못 채운 칸을 **매입 금액 ÷ 기간 평균 주가**로 추정했다.
연간·분기 둘 다 처리한다.

- 평균 주가: Alpaca 월봉 VWAP(분할 미반영 원래 가격)의 거래량 가중 평균. 연간은 종료일까지 12개월(8개월 이상 있어야 함),
  분기는 3개월(2개월 이상). 종료일이 15일 전이면 그 전달을 마지막 달로 본다 (52·53주 회계연도)
- 대상: 매입 금액 > 0이고 주식수가 빈칸인 칸(틀린 companyfacts 값을 뺀 `제외:` 칸 포함), 분기는 companyfacts 0주도 포함
- 거르기: 추정 주식수가 그 기간 발행주식수의 50% 초과 / 평균 주가가 같은 회사 인접 기간(연간 ±2년, 분기 ±4분기) 실제 평균 매입가
  중앙값의 1/3~3배 밖
- 출처 열: `주가 추정: VWAP $<평균 주가>, <n>개월 / 이전: <원래 출처>`. 다시 실행하면 이전 추정을 되돌린 뒤 다시 계산한다
  (같은 결과가 나오는 것 확인). `fill-edgar-buyback`(--recheck 포함)과 `fix-edgar-buyback`은 이 칸을 건드리지 않는다
